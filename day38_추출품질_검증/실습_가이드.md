## 교안 01

1. **스키마 준수율**: 허용 관계와 타입을 지킨 비율을 계산합니다.  
2. **근거 원문 일치율**: 인용 문자열이 출처 원문에 그대로 있는지 검사합니다.  
3. **샘플 정밀도**: 두 검사를 통과한 목록에서 표본을 뽑고 관계가 맞는지 판정합니다.  
4. **골드 작성**: 원문에서 정답 관계를 기록하고 빠뜨린 문장이 없는지 확인합니다.  
5. **골드 완전일치**: TP, FP, FN의 뜻과 정밀도, 재현율, F1을 계산합니다.  
6. **종합 클론코딩**: 논문 데이터의 각 지표를 함수 없이 코드 블록마다 직접 계산합니다.

개념 시연은 가상 도서관 기록 7문장과 대출, 분류 두 스키마를 사용합니다.  
스키마 통과는 5/8, 근거 원문 일치는 4/5입니다.  
표본은 두 검사 통과 4건에서 뽑습니다. 인용 오류로 빠진 관계는 표본의 0점이 아닙니다.  
골드는 그대로 두고 스키마 통과 추출과 두 검사 통과 추출을 각각 비교합니다.

1~5절의 실제 따라하기는 **단위 프로젝트 2의 의약품 자료**로 통일했습니다.  
제품 8개의 통과 140행과 기각 9행을 합쳐 검사하면 스키마 149/149, 원문 일치 146/149입니다.  
두 검사 통과 146행에서 직접 판정할 10행을 뽑습니다.  
골드가 있는 이상반응 관계만 비교하면 TP 40, FP 7, FN 4입니다.

별도 47문서의 표본 50건은 이미 판정이 기록된 자료로 계산하는 예시입니다.  
이는 **Codex의 원문 재검토 판정 예시**이며 사람이 검증한 점수는 아닙니다.  
앞의 8문서 점수와 섞지 않습니다.

## 교안 02

1. 타입, 인용과 의미 오류를 원문에서 확인합니다.  
2. 모순 후보의 출처와 조건을 비교합니다.  
3. 같은 원본에서 타입 한 건과 인용 한 건을 각각 교정합니다.  
4. 같은 문서와 골드로 전후 전체 지표와 정답 손실을 확인합니다.  
5. 개선된 부분과 남은 오류를 보고서에 기록합니다.

논문 기본 점수표는 **스키마 통과 추출 전체**의 값입니다.  
`after_quote_filter`에는 두 검사 통과 결과의 골드 점수를 따로 기록합니다.  
인용만 교정해도 두 검사 통과 목록에 정답 관계가 다시 포함되면 이 목록의 점수가 달라집니다.

의약품 프로젝트의 추가 절 검사까지 적용하면 FP 5건을 줄이지만 정답인 현기 1건도 잃습니다.  
점수가 높아진 이유와 함께 무엇이 사라졌는지 확인하는 실습입니다.

## 종합 실습

01은 **🚀 종합 클론코딩: 품질 지표를 하나씩 계산하기**에서 마칩니다.  
데이터를 읽는 준비 코드 아래, 학생용에는 단계별 주석과 작성 공간이 있고 정답 파일에는 풀이가 있습니다.  
준비 셀을 실행한 뒤 스키마, 근거, TP·FP·FN, 정밀도, 재현율, F1, 표본 선정, 샘플 정밀도 순서로 직접 계산합니다.  
스키마 준수율, 근거 원문 일치율, 정밀도, 재현율과 F1을 하나씩 계산하고 바로 출력합니다.  
표본은 두 검사 통과 목록에서만 고릅니다. 고정 표본 10건의 Codex 판정 예시 점수와 이유는 학생용에도 적혀 있습니다.  
학생은 샘플별 점수를 확인한 뒤 합계와 샘플 정밀도 계산을 직접 작성합니다.  
골드는 논문 6편의 정답 68관계를 제외하거나 수정하지 않고 그대로 사용합니다.  
이 종합 실습에서는 리포트를 만들거나 파일을 저장하지 않습니다.

02의 마지막 예제는 **A. 함수 파트 → B. 메인 실행 파트**로 구성됩니다.  
앞선 실습 없이 실행할 수 있고 모델 호출도 없습니다.  
비교 결과는 `output/lesson02_full/`의 `comparison.json`, `metrics.csv`, `relations.csv`, `reviewed_corrections.json`에 저장합니다.  
여기의 `sample_review.json`은 별도 의약품 50건의 판정 예시입니다.

본문 실습에서는 `my_sample_review.jsonl`, `my_gold.jsonl`, `my_product_metrics.json`과 오류 진단 보고서를 만듭니다.

의약품 골드는 `HAS_SIDE_EFFECT`만 대상으로 합니다. 다른 관계에 이 골드를 적용하지 않습니다.

샘플 정밀도와 골드 정밀도는 판정 방법과 대상이 다르므로 다른 표본의 점수를 골드 F1에 섞지 않습니다.
