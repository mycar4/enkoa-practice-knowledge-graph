# 🛡️ Antigravity Agent Behavioral Constraints & Self-Verification Rules

## 1. 중복 다운로드 및 재실행 절대 금지 (Anti-Duplication)
- 데이터 수집, 배치 처리, API 호출 전 **기존 디스크 산출물(`batch_runs/`, `xml/` 등)의 실제 존재 여부를 반드시 선행 검사**한다.
- 이미 수집된 파일(`rcept_no`)과 중복되는 타겟으로 배치를 재가동하여 API 쿼터를 낭비하는 행위를 전면 금지한다.
- 재실행이 필요한 경우 반드시 사용자에게 기존 데이터와의 차이점을 명시하고 사전 승인을 받는다.

## 2. 실측 기반 보고 원칙 (Zero-Assumption)
- 보고서 작성 및 현황 답변 시 계획서나 기억에 의존한 수치 언급을 금지한다.
- **반드시 실제 디스크/DB를 조회하는 스크립트를 직접 실행한 뒤 반환된 물리적 수치만을 보고**한다.
- 이전 세션과의 불일치나 번복이 발생하지 않도록 답변 전 대화 이력 및 실측 로그를 교차 대조한다.

## 3. 프로덕션 DB 안전 가드 (Production Safety)
- 비인가 스크립트 실행을 금지하며, 오직 검증된 멱등 적재기(`00_Raw_Evidence_Graph_Loader.py`)만 사용한다.
- DB 반영 전 반드시 `DRY-RUN`을 선행하고 사용자의 승인을 득한다.
