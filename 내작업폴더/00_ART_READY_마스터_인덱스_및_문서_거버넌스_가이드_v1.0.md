## 1. 목적과 적용 원칙

이 문서는 ART:READY 산출물의 단일 진실 공급원(SSOT)이다. 발표·심사·외부 협업에서는 아래의 **현재 유효본**만 인용한다. 이전 버전은 삭제하지 않으며, 변경 이력과 검증 증적으로 보존한다.

## 4. 현재 구현 기준 확인값

- `api_art_admission.py`에는 30개 HTTP 라우트가 정의되어 있다. 따라서 과거 문서의 “18개 엔드포인트”는 현재 API 계약의 기준이 될 수 없다.
- FastAPI의 기본 OpenAPI/Swagger 자동 문서는 개발 확인에 사용할 수 있지만, 외부 계약·버전 정책·에러 규격을 갖춘 독립 명세서는 아직 없다.
- GitHub Actions에는 배포와 Neo4j keepalive 워크플로가 존재한다. 그러나 PR 단위 lint·테스트·빌드 품질 게이트는 별도 명세 및 구현이 필요하다.

1. 새 버전은 기존 파일을 덮어쓰지 않고 버전 번호를 올려 작성한다.
