# GPT에게 그대로 전달할 요청문 — 재료 검색 재현율 실패사례 수집

## 배경
학생이 "이 재료로 지원 가능한 학교 찾기" 기능(`POST /prep-search`)에서 재료 이름으로
검색하면, 실제로 그 재료를 허용하는 학교인데도 표기 차이(예: "수채화" 검색 시
"수채물감"이라고만 적힌 학교는 원래 안 잡힘) 때문에 결과에서 누락되는 경우가 있었다.
이번에 동의어 사전을 하나 추가해서 개선했는데, 정확히 몇 % 나아졌는지 재려면
"실제로 놓치는 사례"가 더 많이 필요하다.

## 실행 방법

**API**: `POST https://api.unsuzone.com/art-admission/prep-search`
**요청 형식**: `{"material_query": "<재료명>"}`
**응답**: 그 재료로 매칭된 전형 목록(JSON 배열)

### 1단계: 아래 재료명 20개로 각각 검색 실행
```
수채화, 아크릴, 파스텔, 콩테, 목탄, 크레파스, 연필, 색연필, 붓, 포스터칼라,
과슈, 마카, 켄트지, 지우개, 팔레트, 사인펜, 동양화물감, 유화, 콘테, 물감
```

각 재료마다:
```bash
curl -s -X POST "https://api.unsuzone.com/art-admission/prep-search" \
  -H "Content-Type: application/json" \
  -d '{"material_query":"<재료명>"}'
```

### 2단계: 진짜 놓친 게 있는지 직접 대조
각 재료에 대해, 검색 결과에 **안 나온** 대학 3~5곳을 무작위로 골라서, 그 대학의
**실제 공식 모집요강 원문**(구글에서 "<대학명> 2027학년도 수시모집요강" 검색해서
원문 PDF 찾기)을 열어 "허용 재료" 또는 "준비물" 항목을 확인한다.

- 원문에 그 재료(또는 동의어 표기)가 **실제로 있는데** 검색 결과엔 없다 → **실패 사례**로 기록
- 원문에도 없다 → 정상(검색이 맞게 제외한 것)

### 3단계: 실패 사례를 아래 형식으로 표에 정리해서 보고
| 검색어 | 놓친 대학 | 원문의 실제 표기 | 원문 출처(URL) |
|---|---|---|---|
| 수채화 | OO대학교 | "수채 물감" | (PDF 링크) |

**목표**: 최소 15~20건의 실제 실패 사례. 이게 모이면 재현율을 정확한 숫자로 다시 계산할 수 있다.

## 주의사항
- 절대 원문에 없는 걸 "실패"라고 지어내지 말 것 - 반드시 실제 PDF/원문 확인 후 기록.
- 검색 결과에 이미 잘 나온 재료는 스킵하고, **놓친 것 위주로만** 시간을 쓸 것.
