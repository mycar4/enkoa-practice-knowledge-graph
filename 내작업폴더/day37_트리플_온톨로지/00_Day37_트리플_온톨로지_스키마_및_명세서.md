## 🏷️ 1. 5대 핵심 노드 레이블 (NODE_TYPES)

| 노드 레이블 (Label) | 도메인 정의 | 대표 예시 | 지식그래프 식별자 (ID) |
|---|---|---|:---:|
| `Compound` | 약물, 화합물, 유효 성분 | `Warfarin`, `Aspirin`, `Simvastatin` | DrugBank ID (예: `DB00682`) |
| `Gene` | 인체 유전자, 효소, 수송체 단백질 | `VKORC1`, `CYP2C9`, `CYP3A4` | Entrez Gene ID (예: `7900`) |
| `Disease` | 질병, 임상 질환, 병리적 상태 | `Thrombosis`, `Atrial fibrillation` | Disease Ontology ID (예: `DOID:...`) |
| `Symptom` | 임상 증상, 환자가 호소하는 징후 | `Bleeding`, `Pain`, `Nausea` | MeSH ID (예: `D006470`) |
| `PharmacologicClass`| 약리학적/치료학적 분류군 | `Anticoagulants`, `Statins` | NDF-RT ID (예: `N0000000...`) |
| `Candidate` | 사전 미등재/모호 개체 (격리용) | 신규 연구 물질, 약어 미등록 개체 | 임시 격리 레이블 |

## 🔗 2. 8+1대 관계 시그니처 (RELATION_SIGNATURES)

온톨로지의 관계는 **(주어 타입, 목적어 타입, 판정 기준)** 의 세 칸 튜플로 정의됩니다.

| 관계명 (Relation) | 주어 타입 | 목적어 타입 | 엄격 판정 기준 (Decision Criterion) |
|---|---|---|---|
| `TREATS` | `Compound` | `Disease` | 약이 질병을 치료한다. 질병의 원인이나 진행 자체에 작용한다. |
| `PALLIATES` | `Compound` | `Disease` | 약이 질병의 증상을 완화한다. 질병 자체는 그대로 두고 증상만 덜어 준다. |
| `BINDS` | `Compound` | `Gene` | 약이 그 유전자의 단백질에 결합한다. 대사·수송을 맡는다는 진술도 포함한다 (효소/수송체 통합). |
| `UPREGULATES_CG` | `Compound` | `Gene` | 약이 그 유전자의 발현을 증가시킨다. |
| `DOWNREGULATES_CG` | `Compound` | `Gene` | 약이 그 유전자의 발현을 감소시킨다. |
| `ASSOCIATES` | `Disease` | `Gene` | 질병과 유전자 사이에 연관이 보고됐다. |
| `PRESENTS` | `Disease` | `Symptom` | 질병이 그 증상으로 나타난다. |
| `INCLUDES` | `PharmacologicClass` | `Compound` | 약효 분류가 그 약물을 포함한다 (계열 소속 관계). |
| `RESEMBLES_DD` *(확장)* | `Disease` | `Disease` | 두 질병의 임상 양상이나 발병 기전이 유사하다. |

## 🧬 3. Pydantic 구조화 출력 스키마 명세

```python
from typing import List, Literal, Optional
from pydantic import BaseModel, Field

# 온톨로지 정의와 100% 일치하도록 Literal Enum 제약
RelationName = Literal[
    "TREATS",
    "PALLIATES",
    "BINDS",
    "UPREGULATES_CG",
    "DOWNREGULATES_CG",
    "ASSOCIATES",
    "PRESENTS",
    "INCLUDES",
    "RESEMBLES_DD",
]

NodeType = Literal[
    "Compound", "Disease", "Gene", "PharmacologicClass", "Symptom"
]


class Triple(BaseModel):
  """단일 트리플 추출 단위 스키마"""

  subject: str = Field(description="주어 개체명 (원문에 등장한 그대로)")
  subject_type: NodeType = Field(description="주어 노드 타입")
  relation: RelationName = Field(
      description="허용된 온톨로지 관계 중 가장 적합한 것"
  )
  object: str = Field(description="목적어 개체명 (원문에 등장한 그대로)")
  object_type: NodeType = Field(description="목적어 노드 타입")
  evidence: str = Field(
      description="이 사실을 직접 뒷받침하는 원문 문장 하나 (줄임표 금지)"
  )


class CoTExtraction(BaseModel):
  """CoT 다단계 추론이 결합된 추출 컨테이너"""

  reasoning: str = Field(
      description=(
          "1단계: 개체 식별 -> 2단계: 관계 및 방향 판정 이유를 순서대로 서술"
      )
  )
  triples: List[Triple] = Field(
      description="온톨로지 시그니처에 부합하는 유효한 트리플 목록"
  )
```

## 🧪 4. 3단계 무결성 정제 필터 알고리즘

### [1단계] 근거 대조 (Ground Check)
```python
def ground_check(
    evidence: str, raw_text: str, subject: str, object_: str
) -> bool:
  """근거가 원문에 실제 존재하고, 주어와 목적어가 근거 문장에 포함되어 있는지 검증."""
  if not evidence or evidence not in raw_text:
    return False
  ev_lower = evidence.lower()
  return (subject.lower() in ev_lower) and (object_.lower() in ev_lower)
```

### [2단계] 시그니처 검사 (Signature Check)
```python
def check_signature(row: dict, signatures: dict) -> bool:
  """추출된 관계와 주어/목적어 타입이 온톨로지 시그니처와 100% 일치하는지 검사."""
  rel = row.get("relation")
  if rel not in signatures:
    return False
  subj_type, obj_type, _ = signatures[rel]
  return (row.get("subject_type") == subj_type) and (
      row.get("object_type") == obj_type
  )
```

### [3단계] 복합키 중복 제거 (Drop Duplicates)
```python
def drop_duplicates(rows: list[dict]) -> list[dict]:
  """(subject, relation, object) 튜플을 기준으로 중복 트리플을 제거."""
  seen = set()
  unique_rows = []
  for row in rows:
    key = (row["subject"].lower(), row["relation"], row["object"].lower())
    if key not in seen:
      seen.add(key)
      unique_rows.append(row)
  return unique_rows
```

## 🌐 5. Neo4j Cypher 적재 패턴 및 계층 명세

### 1) 노드 패턴 생성 (Node Pattern)
```cypher
// 1. 사전 매칭 성공 시 (표준 ID 노드)
MERGE (s:Compound {id: $subj_id})
ON CREATE SET s.name = $subj_name

// 2. 사전 미등재/모호 시 (Candidate 격리 노드)
MERGE (s:Candidate {name: $subj_name})
ON CREATE SET s.isolated_at = datetime()
```

### 2) 관계 생성 및 근거 등급 불변식 (Evidence Invariant)
```cypher
// 관계 생성 및 근거 속성 적재 (curated가 reported로 강등되지 않도록 coalesce 처리)
MERGE (s)-[r:TREATS]->(o)
ON CREATE SET 
    r.evidence = $evidence,
    r.doc_id = $doc_id,
    r.evidence_level = $evidence_level,
    r.created_at = datetime()
ON MATCH SET
    r.evidence_level = CASE 
        WHEN r.evidence_level = 'curated' THEN 'curated' 
        ELSE $evidence_level 
    END,
    r.updated_at = datetime()
```

### 3) 노드 타입 계층 (TYPE_HIERARCHY)
```python
TYPE_HIERARCHY = {
    "Enzyme": "Gene",
    "Transporter": "Gene",
    "Cytokine": "Gene",
    "Autoimmune": "Disease",
}


def labels_for(node_type: str) -> list[str]:
  """상위 계층을 포함한 다중 레이블 목록 반환 (예: Enzyme -> ['Gene', 'Enzyme'])."""
  parent = TYPE_HIERARCHY.get(node_type)
  if parent:
    return [parent, node_type]
  return [node_type]
```
