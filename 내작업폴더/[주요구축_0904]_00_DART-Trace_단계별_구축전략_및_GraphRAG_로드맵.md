## 🎯 0. DART-Trace의 본질적 목적 및 멀티에이전트 점진적 분리 전략

### 1) 서비스가 지향하는 진짜 가치
DART-Trace는 막연한 '주가 예측 AI'나 단순 '공시 검색기'가 아닙니다.  
투자자가 스스로 내린 의사결정을 객관적으로 검증할 수 있도록, **공식 공시·재무·자본이벤트·지분변동 원문과 시장 가격을 결합하여 사실과 해석을 명확히 분리해 제공하는 근거 엔진**입니다.

```text
[DART 공시 · 재무(XBRL) · 자본이벤트(CB/BW/증자)]
              +
[대주주 · 5% 지분변동 원문 증거]
              +
[회사 공식 IR · 거래소(KRX) 공시 · 공식 보도자료]
              │
              ▼
   "단일 기업 대상: 무엇이 바뀌었고, 앞으로 무엇을 확인해야 하는가?" 
   (사실 / 해석 / 원문 근거 / 다음 확인 항목 4단 코어 엔진 완성)
              │
              ▼ (기본 서비스 완성 후 확장)
   [사용자 포트폴리오 + 현재 시세/수익률 결합 ➔ 복수 보유종목 일괄 리포트]
```

### 2) 점진적 계층 분리 원칙 (Incremental Tiering Architecture)
기존 파일의 대량 이사로 인한 경로 충돌과 회귀 오류를 방지하기 위해, **기존 코드는 온전히 보존하고 새 기능부터 계층을 분리하는 점진적 아키텍처**를 엄격히 준수합니다.

* **지금 하지 않을 것 (대량 이사 금지)**:
  - 루트의 `day27~day35` 교안 폴더 대량 이동 금지
  - `내작업폴더/` 전체 폴더명 변경 금지
  - 기존 수집기/배치/검증기 경로 일괄 변경 금지
* **새 기능부터 적용하는 계층 구조**:
  - `내작업폴더/app_dart_trace_dashboard.py`: 당분간 Streamlit 진입점 및 메뉴 라우터 유지
  - `내작업폴더/ui/` (**Claude 소유**): 화면 디자인, 페이지 컴포넌트, 프레젠테이션 가공
  - `내작업폴더/services/` (**Antigravity 소유**): 읽기 전용 쿼리 서비스, 4단 리포트 데이터 엔진
  - `내작업폴더/data_pipeline/` (**Antigravity 소유**): 수집기, 로더, 해소/승격 배치
  - `내작업폴더/tests/`: UI, 서비스, 파이프라인 무결성 검증 테스트

2. **“현재 가격 하락 구간에서, 최근 공식 공시상 확인된 희석 위험·재무 변화·대주주 변동은 무엇인가?”**

### 3) 답변 응답 계약 (Fact vs Interpretation Separation)
사용자에게 제공되는 AI의 모든 답변은 철저히 4단 구조로 분리되어야 합니다:

| 구분 | 서비스가 확정적으로 말하는 것 (Fact & Evidence) | AI가 분석적으로 제시하는 것 (Interpretation & Action) |
| :--- | :--- | :--- |
| **사실 (Fact)** | 현재가, 보유수량, 매수평단, 공시일자, CB/BW 전환가액·리픽싱 조건, 증자규모, 지분율 변동, OpenDART XBRL 재무 수치 | — |
| **해석 (Interpretation)** | — | 잠재적 지분 희석 위험, 자금조달에 따른 재무부담, 성장 촉매, 긍정/중립/부정 시나리오 |
| **원문 근거 (Evidence)** | DART 접수번호, XML SHA-256, 표준 1-based XPath, 원문 행 해시, DART 공식 원문 링크 | — |
| **다음 확인 항목 (Next Action)** | — | 청약일/납입일, 전환청구가능일, 후속 정기공시, 대주주 지분 모니터링 체크리스트 |

## 🔍 1. 현행 구축 자산 및 개발 순서 원칙

### 1) 이미 구축된 강력한 기반 (Strong Foundation)
- **대주주·5% 지분변동 원문 증거 계층**: 23,996건 추출 후보 및 51,551건 증거 파편 (표준 XPath, 암호학적 행 해시 결속)
- **주요 자본이벤트 팩트**: 313건 CB·BW·유상증자 (`DART_CapitalEvent`)
- **상장사 정규화 마스터**: 3,988개사 (`DART_Company`)
- **엔티티 해소 무결성 계약 v1.2**: 500건 표본 재감사 완료 (PASS 19건, AMBIGUOUS 308건, REJECT 173건, $\Delta=0$)
- **승격 실행기 v2.1 4대 안전성 보강**: 표준 XPath, 정규식/숫자형 대조, 단일 트랜잭션, 재실행 no-op 회계 완료

### 2) 개발 순서의 절대 원칙 (사용자 피드백 반영)
> 🚨 **"기본 서비스(단일 기업 대상 4단 의사결정 엔진 및 GraphRAG)를 먼저 완성하고, 포트폴리오와 시세는 그 뒤에 얹는다."**
> 
> 단일 기업(예: 알루코, 파마리서치)을 입력했을 때 4단 리포트가 나오지 않으면, 포트폴리오 기능은 단순한 빈 껍데기에 불과합니다. 단일 기업 코어 엔진이 완성되면, 포트폴리오는 단순한 `WHERE IN [...]` 필터 확장에 불과합니다.

## 🧭 2. 재조정된 정석 실행 파이프라인 (Execution Pipeline)

```text
[ 1단계: 원문 증거 계층 & 해소 무결성 검증 (완료 🟢) ]
  • PASS 19건 경제적 보유 관계 DRY-RUN 완료 및 승격 실행기 v2.1 안전성 보강 완료
  • 사명 변경 98건 DEFERRED_HISTORICAL_NAME 안전 보류 (DB 쓰기 0건 보존)

       │
       ▼
[ 2단계: 단일 기업 대상 4단 의사결정 코어 엔진 구축 (차기 최우선 착수 ⚪) ]
  • 메뉴 2 전면 개편: 단일 기업 입력 시 [사실 / 해석 / 원문 근거 / 다음 확인] 4단 리포트 생성
  • CB/BW 희석 위험, 유상증자 목적(시설투자 vs 채무상환), 대주주 변동 시나리오 분석기 탑재

       │
       ▼
[ 3단계: OpenDART XBRL 재무제표 & 공식 채널 타임라인 결합 (⚪) ]
  • OpenDART 재무 API 연동 (부채비율, 유동비율, 영업이익) 사실 계층 바인딩
  • DART 공시 + KRX KIND 상장공시 + 기업 공식 IR 일정 타임라인 결합

       │
       ▼
[ 4단계: True Day 35 Hybrid GraphRAG 파이프라인 완성 (⚪ 기본 서비스 완성) ]
  • 자본이벤트 512차원 Neo4j Vector Index (text-embedding-3-small) 구축
  • GDS Louvain 커뮤니티 사전 필터 & MinMax 70:30 (유사도:PageRank) 하이브리드 리랭커 가동
  • 2D XPath + 해시 원문 근거 100% 결속 QA 프로덕션 배포

       │ (기본 코어 서비스 100% 검증 완료 후)
       ▼
[ 5단계: 사용자 포트폴리오 & 시장 시세 레이어 확장 (⚪ 사용자 경험 확장) ]
  • 사용자 포트폴리오 로컬/비공개 저장 (종목코드, 수량, 매수단가)
  • 현재 시세 및 평가손익 피드 결합
  • 복수 보유 종목 일괄 이벤트 모아보기 ("내 보유종목 중 이번달 CB 나온 기업?")
```

## 🚀 3. 단계별 상세 추진 전략 (Phase 1 ~ Phase 5)

### 📌 [Phase 1] 원문 증거 계층 및 엔티티 해소 무결성 검증 (완료 🟢)
1. **15,000건 공시 수집 및 Cloud Aura 적재**: 23,996 후보 및 51,551 증거 파편 적재.
2. **엔티티 해소 v1.2 500건 표본 재감사**:
   - 대상회사명 일치(Rule 1), 증거 파편 값 일치(Rule 4), 달력 실존 일자(Rule 5) 검증.
   - 결과: PASS 19건, AMBIGUOUS 308건, REJECT 173건 (변조 거부 테스트 6/6 통과, $\Delta=0$).
3. **PASS 19건 경제적 보유 관계 DRY-RUN 및 실행기 v2.1 보강**:
   - 정규식 및 숫자형 정밀 대조 100% 통과.
   - 표준 XPath 분리, 단일 원자적 트랜잭션, 3분할 회계(`created/already_existing/rejected`) 적용.
   - 2023년 보고의무발생일 기준 과거 사실 시간적 의미 고정 (DB 쓰기 0건 유지).

### 📌 [Phase 2] 메뉴 2 전면 개편: 4단 의사결정 리포트 엔진 (차기 핵심 착수 ⚪)
1. **스프린트 2.1 (단일 기업 4단 리포트 생성기)**:
   - 특정 종목코드/사명 입력 시 Aura DB의 자본이벤트(CB/BW/증자)와 5% 지분변동을 실시간 집계.
   - 응답 구조: `사실(수치/일자)` ➔ `해석(희석위험/시나리오)` ➔ `원문 근거(XPath/해시/링크)` ➔ `다음 확인(납입/전환일)`.
2. **스프린트 2.2 (리스크 및 시나리오 프롬프트 엔지니어링)**:
   - 오버행(희석) 부담률 계산, 자금조달 목적성 평가(운영자금 vs 시설투자), 대주주 지분 감소 시나리오 평가.

### 📌 [Phase 3] OpenDART 재무 연계 및 공식 채널 타임라인 (⚪)
1. **스프린트 3.1 (OpenDART XBRL 재무제표 결합)**:
   - [OpenDART 재무정보 API](https://opendart.fss.or.kr/guide/main.do?apiGrpCd=DE003) 연동을 통한 주요 재무지표(부채비율, 유동비율, 이자보상배율) 사실 계층 바인딩.
2. **스프린트 3.2 (출처별 공식 채널 타임라인)**:
   - DART 공시(A급), KRX KIND 상장공시(A급), 기업 공식 IR/보도자료(B급) 타임라인 통합 뷰 제공.

### 📌 [Phase 4] True Day 35 Hybrid GraphRAG 파이프라인 완성 (⚪ 기본 서비스 완성)
1. **스프린트 4.1 (자본이벤트 512차원 Neo4j Vector Index)**:
   - `DART_CapitalEvent` 목적 서술문 임베딩 생성 및 Neo4j Vector Index 구축.
2. **스프린트 4.2 (MinMax 70:30 하이브리드 리랭커)**:
   - 질문 적합성(70%)과 PageRank/자본규모(30%) 정규화 융합 엔진 탑재.
   - 최종 프로덕션 배포 Sign-off.

### 📌 [Phase 5] 사용자 포트폴리오 및 시세 피드 확장 (⚪ 사용자 경험 확장)
1. **스프린트 5.1 (로컬 비공개 포트폴리오 매니저)**:
   - `portfolio.json` 로컬 암호화/비공개 스토리지 구현 (종목코드, 수량, 매수단가, 매수일).
   - "내 보유 종목 일괄 4단 진단 리포트" 기능 활성화.
2. **스프린트 5.2 (현재가 및 평가손익 결합 레이어)**:
   - 보유 종목 대상 일별/실시간 시세 연동 (현재가, 일간 등락률, 평가금액, 수익률 계산).
