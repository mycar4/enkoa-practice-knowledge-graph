## 🎯 학습 목표
1. **원천 데이터 정제 거버넌스**: 공공데이터(CP949)의 인코딩을 Python으로 감지하고 UTF-8로 안전하게 변환하는 원리를 이해합니다.
2. **스키마 제약조건 선행 구축**: `NODE KEY` 및 `UNIQUE` 제약조건을 사전 빌드하여 `MERGE` 연산의 풀스캔 병목을 방어합니다.
3. **`LOAD CSV` 형변환 및 결측치 방어**: `toInteger`, `toFloat`, `coalesce`, `trim`을 활용해 문자열 원천 데이터를 완벽히 형변환합니다.
4. **`apoc.load.json` 계층 데이터 분해**: 중첩 JSON 배열을 `UNWIND`하여 복합 그래프 노드 및 엣지를 생성합니다.
5. **서브쿼리 분할 트랜잭션**: `CALL { ... } IN TRANSACTIONS OF 1000 ROWS`로 대용량 데이터 적재 시 힙 메모리 OOM을 방지합니다.

## 🛠️ 1. 환경 설정 및 사전 준비 (4대 점검 사항)

### 1) APOC 플러그인 확인
* Neo4j 인스턴스에서 `RETURN apoc.version();` 쿼리가 버전 문자열을 반환하는지 확인합니다.

### 2) `import` 디렉터리 경로 설정
* `LOAD CSV`와 `apoc.load.json`은 보안상 서버의 `import` 디렉터리 안의 파일만 읽습니다.
* `.env` 파일에 `NEO4J_IMPORT_DIR` 경로를 등록하거나, `data/` 안의 파일들을 해당 `import` 폴더로 복사합니다.

### 3) `apoc.conf` 파일 생성 (`conf/apoc.conf`)
* APOC의 파일 읽기 권한을 활성화하기 위해 `conf/apoc.conf` 파일에 아래 설정을 추가하고 DB를 재시작합니다:
  ```properties
  apoc.import.file.enabled=true
  apoc.import.file.use_neo4j_config=true
  ```

### 4) `.env` 접속 정보 검증
```dotenv
NEO4J_URI=bolt://localhost:7687
NEO4J_USER=neo4j
NEO4J_PASSWORD=본인비밀번호
NEO4J_IMPORT_DIR=로컬_임포트_경로
```

## 📚 2. 교안별 핵심 내용 정리

### 📘 교안 01: 적재 순서 및 멱등성 (Loading Order & Idempotency)
* **핵심 원칙**:
  1. **노드 선행 ➔ 관계 후행**: 출발 노드와 도착 노드가 먼저 존재해야 관계(`MERGE (a)-[r]->(b)`) 생성이 누락되지 않습니다.
  2. **제약조건 선행**: 제약조건이 없으면 노드 10만 개 생성 시 $O(N^2)$ 시간이 소요됩니다.
  3. **`MERGE` 멱등성**: 네트워크 단절 등으로 스크립트를 재실행해도 노드가 중복 생성되지 않도록 키 프로퍼티를 명확히 지정합니다.

### 📘 교안 02: 스키마 설계 및 온톨로지 정규화 (Schema Design)
* **복합 식별자(`NODE KEY`)**: 역명(`name`)만으로는 '1호선 시청역'과 '2호선 시청역'을 구분할 수 없으므로 `(name, line)`을 복합 키로 묶습니다.
* **날짜의 노드 승격**: 단순 프로퍼티(`r.day = '월요일'`) 대신 요일 노드(`(:Day {name: '월요일'})`)로 승격하여 요일별 비교 집계 쿼리를 그래프 탐색으로 고속화합니다.

### 📘 교안 03: 파일 적재 실무 (`LOAD CSV` & `APOC`)
* **CSV 읽기**:
  ```cypher
  LOAD CSV WITH HEADERS FROM 'file:///seoul_metro_transfer_utf8.csv' AS row
  MERGE (s:Station {name: trim(row.역명), line: trim(row.호선)})
  SET s.transfer_passengers = toInteger(coalesce(row.환승인원, '0'));
  ```
* **JSON 읽기**:
  ```cypher
  CALL apoc.load.json('file:///seoul_metro_lines.json') YIELD value
  UNWIND value.lines AS line
  MERGE (l:Line {line_id: line.line_id})
  SET l.name = line.line_name;
  ```
* **대용량 트랜잭션 분할**:
  ```cypher
  LOAD CSV WITH HEADERS FROM 'file:///hetionet_edges.csv' AS row
  CALL {
      WITH row
      MATCH (s {id: row.source_id}), (t {id: row.target_id})
      MERGE (s)-[r:RELATION {type: row.metaedge}]->(t)
  } IN TRANSACTIONS OF 1000 ROWS;
  ```

## 💡 4. 자주 발생하는 트러블슈팅 (FAQ)

| 증상 | 원인 | 조치 방법 |
|---|---|---|
| `Cannot load external resource file:/...` | `import` 폴더에 파일이 없음 | `data/` 폴더 안의 CSV/JSON 파일들을 Neo4j `import` 폴더로 복사 |
| `Import from files not enabled` | `apoc.conf` 미설정 | `conf/apoc.conf` 파일에 `apoc.import.file.enabled=true` 추가 후 DB 재시작 |
| 한글이 `???` 또는 외계어로 깨짐 | 원본 인코딩이 `CP949`임 | Python `read_text('cp949')` ➔ `write_text('utf-8')` 변환본 파일 사용 |
| `Node Key constraint requires Enterprise` | Community Edition 사용 중 | Desktop 로컬 Enterprise 라이선스 또는 UNIQUE fallback 사용 |
