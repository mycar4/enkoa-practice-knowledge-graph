> **문서 목적**: Day 32에서 다루는 2대 핵심 도메인 데이터셋(**1. 서울 대중교통 메트로 환승망**, **2. Hetionet 의생명 바이오 메디컬 지식그래프**)의 노드 레이블, 관계 타입, 프로퍼티 데이터 타입, 제약조건 DDL, 및 소스 파일 매핑 규격을 공식 정의합니다.

## 1. 🚇 도메인 A: 서울 지하철 대중교통 지식그래프 스키마

### 1.1 노드 스키마 (Node Schemas)

#### ① `:Station` (지하철 역 엔터티)
* **정의**: 특정 호선에 속한 지하철 역사
* **복합 식별자(NODE KEY)**: `(name, line)`
* **속성 명세**:
  * `name`: 역명 (String, 예: `'강남'`, `'신도림'`, `'동대문역사문화공원'`)
  * `line`: 호선명 (String, 예: `'2호선'`, `'1호선'`)
  * `station_cd`: 역 코드 (String, 선택)
  * `transfer_type`: 환승역 여부 (Boolean, 예: `true`, `false`)
  * `daily_avg_passengers`: 일평균 환승/승하차 승객수 (Integer)

#### ② `:Line` (노선 엔터티)
* **정의**: 지하철 운행 노선
* **식별자(UNIQUE)**: `line_id`
* **속성 명세**:
  * `line_id`: 노선 고유 ID (String, 예: `'LINE_1'`, `'LINE_2'`)
  * `name`: 노선 공식 명칭 (String, 예: `'1호선'`, `'2호선'`)
  * `color`: 노선 대표 색상 코드 (String, 예: `'#0052A4'`, `'#00A84D'`)
  * `total_stations`: 총 역사 수 (Integer)

#### ③ `:Day` (요일 엔터티)
* **정의**: 환승 통계 집계 기준 요일
* **식별자(UNIQUE)**: `name`
* **속성 명세**:
  * `name`: 요일명 (String, 예: `'월요일'`, `'화요일'`, `'토요일'`, `'일요일'`)
  * `day_of_week`: 요일 번호 (Integer, `1`=월 ~ `7`=일)
  * `is_weekend`: 주말 여부 (Boolean)

---

### 1.2 관계 스키마 (Relationship Schemas)

#### ① `[:BELONGS_TO]` (`(:Station)-[:BELONGS_TO]->(:Line)`)
* **의미**: 역이 특정 노선에 소속됨을 정의
* **속성**:
  * `station_seq`: 노선 내 역 순번 (Integer)

#### ② `[:NEXT_STATION]` (`(:Station)-[:NEXT_STATION]->(:Station)`)
* **의미**: 동일 노선 상의 인접 역 간 운행 연결
* **속성**:
  * `distance_km`: 역간 거리 (Float, 단위: km)
  * `duration_min`: 소요 시간 (Float, 단위: 분)

#### ③ `[:TRANSFERS_TO]` (`(:Station)-[:TRANSFERS_TO]->(:Station)`)
* **의미**: 환승역 내 서로 다른 호선 간 환승 통로 연결
* **속성**:
  * `transfer_time_min`: 평균 환승 소요 시간 (Float)
  * `walk_distance_m`: 환승 보행 거리 (Integer)

#### ④ `[:HAS_TRANSFER_STAT]` (`(:Station)-[:HAS_TRANSFER_STAT]->(:Day)`)
* **의미**: 역별 요일 환승 승객 통계
* **속성**:
  * `passenger_count`: 환승 승객수 (Integer)
  * `as_of_year`: 기준 연도 (Integer, 예: `2024`)

## 2. 🧬 도메인 B: Hetionet 바이오 메디컬 지식그래프 스키마

### 2.1 노드 스키마 (Node Schemas)

| 노드 레이블 | 엔터티 설명 | 주요 속성 | 고유 식별자 | 예시 ID |
|---|---|---|---|---|
| **`:Compound`** | 약물 및 화합물 | `id`, `name`, `inchikey` | `id` (UNIQUE) | `Compound::DB00001` |
| **`:Disease`** | 질병 및 증상 | `id`, `name`, `mesh_id` | `id` (UNIQUE) | `Disease::DOID:10652` |
| **`:Gene`** | 인간 유전자 | `id`, `name`, `symbol`, `chromosome` | `id` (UNIQUE) | `Gene::9021` |
| **`:Anatomy`** | 신체 해부학적 부위 | `id`, `name`, `bto_id` | `id` (UNIQUE) | `Anatomy::UBERON:0000955` |
| **`:Pathway`** | 생체 대사 경로 | `id`, `name`, `source` | `id` (UNIQUE) | `Pathway::PW:0000001` |

---

### 2.2 관계 스키마 (Relationship Schemas)

| 관계 타입 | 출발 노드 ➔ 도착 노드 | 의미적 정의 (Semantics) | 주요 속성 |
|---|---|---|---|
| **`[:TREATS]`** | `(:Compound) ➔ (:Disease)` | 화합물이 질병을 치료함 | `source`, `evidence_level` |
| **`[:PALLIATES]`** | `(:Compound) ➔ (:Disease)` | 화합물이 질병 증상을 완화함 | `source` |
| **`[:CAUSES]`** | `(:Compound) ➔ (:Disease)` | 약물이 부작용으로 질병을 유발함 | `source` |
| **`[:ASSOCIATES]`** | `(:Gene) ➔ (:Disease)` | 유전자 변이가 질병과 연관됨 | `p_value`, `source` |
| **`[:BINDS]`** | `(:Compound) ➔ (:Gene)` | 화합물이 특정 표적 유전자 단백질에 결합함 | `affinity_nm`, `action_type` |
| **`[:EXPRESSES]`** | `(:Anatomy) ➔ (:Gene)` | 특정 장기/조직에서 유전자가 발현됨 | `expression_level` |

## 3. 🔒 Neo4j DDL 제약조건 (Constraints Definition)

```cypher
// 1. 서울 메트로 복합 키 (NODE KEY)
CREATE CONSTRAINT metro_station_node_key IF NOT EXISTS
FOR (s:Station) REQUIRE (s.name, s.line) IS NODE KEY;

CREATE CONSTRAINT metro_line_id_unique IF NOT EXISTS
FOR (l:Line) REQUIRE l.line_id IS UNIQUE;

CREATE CONSTRAINT metro_day_name_unique IF NOT EXISTS
FOR (d:Day) REQUIRE d.name IS UNIQUE;

// 2. Hetionet 엔터티 단일 키 (UNIQUE)
CREATE CONSTRAINT hetio_compound_id_unique IF NOT EXISTS
FOR (c:Compound) REQUIRE c.id IS UNIQUE;

CREATE CONSTRAINT hetio_disease_id_unique IF NOT EXISTS
FOR (d:Disease) REQUIRE d.id IS UNIQUE;

CREATE CONSTRAINT hetio_gene_id_unique IF NOT EXISTS
FOR (g:Gene) REQUIRE g.id IS UNIQUE;

CREATE CONSTRAINT hetio_anatomy_id_unique IF NOT EXISTS
FOR (a:Anatomy) REQUIRE a.id IS UNIQUE;
```
