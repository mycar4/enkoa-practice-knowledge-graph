# 데이터 명세서 — `01_핸즈온_실습.ipynb`에서 쓰는 가짜 문서 7개

핸즈온 노트북은 API 키·DB 연결 없이 그 자리에서 실행되도록, 실제 홍익대학교
청크의 **내용을 그대로 흉내 낸 가짜 문서 7개**를 코드 안에 직접 박아뒀습니다.
(진짜 Neo4j 데이터가 아닙니다 — 실제 데이터는 `services/art_admission_service.py`가
운영 DB에서 직접 조회합니다.)

| ID | 주제 | 실제로 대응하는 진짜 사례(오늘 실측에 쓰인 것) |
|---|---|---|
| D1 | 미술활동보고서 글자수 제한 | "600자 이내" 유형 질문의 정답 청크 |
| D2 | 정정요청 방법 | "정정요청은 어떻게 하나요" 질문의 정답 청크 |
| D3 | 평가거부 방법 | "평가거부는 어떻게 하나요" 질문의 정답 청크 |
| D4 | 재료 준비물(수채화 등) | 재료 매칭 개선 작업에서 다룬 재료 목록 |
| D5 | 논술고사 시험시간 | "논술고사 시험시간이 몇 분이야" 질문의 정답 청크 |
| D6 | 평가자 회원가입 | "평가자 회원가입은 어떻게 하나요" 질문의 정답 청크 |
| D7 | 재직사실확인서 제출 | "재직사실확인서는 어떻게 제출하나요" 질문의 정답 청크 |

## 필드 구조
```json
{"id": "D1", "text": "실제 청크 내용을 짧게 요약한 한두 문장"}
```

## 왜 진짜 데이터를 안 쓰는가
1. 실습 환경에 Neo4j 접속 정보/OpenAI API 키가 없어도 누구나 바로 실행할 수 있어야 합니다.
2. 진짜 임베딩(OpenAI) 대신 `hashlib` 기반 가짜 임베딩을 쓰므로, 진짜 청크 원문을
   그대로 넣어도 정확도가 보장되지 않습니다 — 개념 체험이 목적이지 정확도 벤치마크가
   아닙니다. **정확한 벤치마크 숫자는 `01_핸즈온_실습.ipynb` 6번 셀([우리 서비스 실 사례])의
   진짜 운영 데이터 측정값을 보세요.**
