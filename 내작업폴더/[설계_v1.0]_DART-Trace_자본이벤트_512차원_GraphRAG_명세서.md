## 🔍 2. Neo4j 인덱스(Index) 상세 규격

### 1) HNSW 코사인 벡터 인덱스 (`dart_capital_event_vector_idx`)
* **대상 라벨**: `:DART_CapitalEvent`
* **대상 속성**: `embedding_512`
* **차원 수 (Dimensions)**: 512
* **거리 유사도 (Metric)**: `cosine`
* **생성 쿼리**:
  ```cypher
  CREATE VECTOR INDEX dart_capital_event_vector_idx IF NOT EXISTS
  FOR (e:DART_CapitalEvent)
  ON (e.embedding_512)
  OPTIONS {
    indexConfig: {
      `vector.dimensions`: 512,
      `vector.similarity_function`: 'cosine'
    }
  };
  ```

### 2) 기업명 및 자금조달 목적 Fulltext 전문 인덱스 (`dart_purpose_fulltext_idx`)
* **대상 라벨 및 속성**: `:DART_CapitalEvent(purpose_text, corp_name)`
* **생성 쿼리**:
  ```cypher
  CREATE FULLTEXT INDEX dart_purpose_fulltext_idx IF NOT EXISTS
  FOR (e:DART_CapitalEvent)
  ON EACH [e.purpose_text, e.corp_name];
  ```

## ⚙️ 3. MinMax 70:30 하이브리드 리랭킹 알고리즘

질문 적합도(의미 유사도)와 실물 자본 규모/네트워크 중요도를 수학적으로 정규화하여 융합합니다.

### 1) 점수 융합 수식
$$\text{Final\_Score} = 0.70 \times \text{Sim}_{\text{norm}}(q, e) + 0.30 \times \left( 0.5 \times \text{Scale}_{\text{norm}}(e) + 0.5 \times \text{PR}_{\text{norm}}(c) \right)$$

* $\text{Sim}_{\text{norm}}$: 질문 벡터 $q$와 목적 벡터 $e$ 간의 코사인 유사도 ($[0, 1]$ 정규화)
* $\text{Scale}_{\text{norm}}$: 당해 자본조달 금액의 로그 스케일 정규화 ($\log_{10}(\text{amount})$)
* $\text{PR}_{\text{norm}}$: 해당 기업의 GDS 지배구조 네트워크 PageRank 점수

## 🛡️ 4. 답변 응답 계약 (Fact vs Interpretation)

DART-Trace QA 응답은 철저히 4단으로 구성되며 환각(Hallucination)을 원천 차단합니다:

1. **사실 (Fact)**: 조달 금액, 전환가액, 표면/만기이자율, 납입일자, 발행 주식수
2. **해석 (Interpretation)**: 주주가치 희석률(오버행 위험), 자금조달 성격(운영자금형 vs 시설투자형)
3. **원문 근거 (Evidence)**: DART 접수번호(14자리), XML SHA-256, 1-based XPath, 원본 공시 링크
4. **다음 확인 항목 (Next Action)**: 전환청구 가능 시작일, 청약/납입 예정일 모니터링 포인트
