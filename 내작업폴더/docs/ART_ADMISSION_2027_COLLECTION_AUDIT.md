# 2027 미술·디자인 입시 수집·재검증 보드

최종 갱신: 2026-09-10

이 보드는 2027 모집요강을 기준으로 한 작업 현황이다. `완료`는 공식 원문 저장, 같은 학과의 모든 전형 챕터 대조, 일정 3종 확인, 학생부 정량/정성 구분, JSON 검증까지 끝난 경우에만 사용한다. DB 적재 상태와는 별개다.

## 실시간 작업 상태

| 항목 | 현재 상태 |
|---|---|
| 작업 단계 | 34개교 원문 재대조: 같은 학과의 전형 누락·인접 행 수치·일정·학생부 규칙 확인 |
| 마지막 완료 | 이화여대·동덕여대·덕성여대 미술 전형 10건: 모집표·일정·실기 대조 |
| 현재 작업 | 잔여 대학별 모집표·일정·학생부 전형 대조 |
| 다음 갱신 조건 | 대학 1곳 또는 검증 배치가 끝날 때마다 이 표와 최근 검증 결과를 갱신 |
| DB 상태 | DRY-RUN만 수행, `--commit` 미실행 |
