## 🧭 2. 10대 메뉴별 심층 특장점 및 실측 동작 분석

### 🏫 [메뉴 1] 학교/학과 목록
* **특장점**:
  * 14개 주요 미술대학의 학과 개설 현황 실시간 조회.
  * **허용재료/실기규격 키워드 실시간 필터링** (예: `연필`, `켄트지`, `수채화` 입력 시 해당 재료 허용 학교만 즉시 압축).
  * 시스템 현재 일자 기준 **`접수마감 D-Day` 실시간 배지** 연동.

### 🔍 [메뉴 2] 학교 상세 정보
* **특장점**:
  * 대학별/학과별 전형 요강 공식 사실 전수 출력 (정원, 반영비율, 실기종목, 시험시간, 용지규격, 3원 일정).
  * **출처 신뢰도 자동 분류 배지**: `🟢 대학 자체 공식 사이트` vs `🟡 제3자 CDN 미러` 색상 분리.
  * **합격선 추정치 분리 렌더링**: 공식 사실 카드와 합격선 추정치 카드를 물리적·시각적으로 100% 격리.

### ⚖️ [메뉴 3] 전형 1:1 비교
* **특장점**:
  * 지원 고민 대학 간 실기 반영비율 vs 교과/수능 반영비율 1:1 병렬 대조.
  * 실기고사 시간 및 용지 규격 차이 직관적 비교.

### 📅 [메뉴 4] 일정 캘린더
* **특장점**:
  * 월간 그리드 캘린더 엔진 (`_render_month_calendar`).
  * 4대 이벤트 유형별 고유 컬러 태깅: 원서접수(파랑), **실기고사(빨강 - 위험 신호)**, 합격발표(초록), 등록(보라).
  * 오늘 날짜 하이라이트 및 동일 대학 다중 학과 이벤트 자동 그룹화.

### 🎯 [메뉴 5] 동시지원 시뮬레이터 (킬러 기능)
* **특장점**:
  * 수시 최대 6개 대학 선택 시 **실기고사일 중복 여부를 1초 만에 자동 탐지 (`detect_schedule_conflicts`)**.
  * 학년도가 다른 전형은 비교 대상에서 원천 배제하여 연도 혼선 방지.

### 📝 [메뉴 6] 기출문제 아카이브
* **특장점**:
  * 최근 5개년 대학별/실기종목별 실제 출제 문제 및 제시물 데이터 영구 보존.

### 🚦 [메뉴 7] 데이터 정합성 센터
* **특장점**:
  * 적재된 전형 데이터의 결손치(일정 미정, 규격 누락 등)를 실시간 감사하여 `WARNING`/`INFO`로 보고.

### 💬 [메뉴 8] 질의응답 (GraphRAG 탑재 핵심 엔진)
* **특장점**:
  1. **이중 답변 엔진 (Double-Engine)**:
     - `규칙기반 답변`: Cypher 그래프 DB에서 조회된 확정 팩트만 출력 (환각 0%).
     - `AI 답변`: 지식그래프 팩트 + PDF 원문 청크 하이브리드 검색 + 개체 그래프 연관 문맥을 종합한 자연어 답변.
  2. **하이브리드 리트리버 & AI Reranker**:
     - `admission_chunk_embedding` (768차원 코사인 유사도) + `admission_chunk_fulltext` (Lucene 전문 검색) 융합 점수 계산.
     - `gpt-4o-mini`를 통한 상위 5개 청크 **재순위화(0~10점) 및 근거 페이지 Expander 노출**.
  3. **멀티 LLM 게이트웨이**:
     - GPT-4o, GPT-5.5, o4-mini, Claude 3.5 Sonnet, Gemini 1.5 Pro 지원.

### 🖊️ [메뉴 9] 서류 AI 첨삭 (GraphRAG 연동)
* **특장점**:
  * 학생이 제출한 자기소개서/미술활동보고서 텍스트에서 **지식그래프 엔티티를 자동 탐지(`detect_entities_in_text`)**.
  * 학생 글이 속한 **전공 군집(Louvain Community Label)**을 파악하여 맞춤형 글쓰기 가이드 제공.
  * Streamlit `st.chat_message` 기반 **멀티턴 대화형 연속 첨삭 스레드** 지원.

### 🕸️ [메뉴 10] 지식그래프 보기 (신규 런칭)
* **특장점**:
  * **뷰 1 (구조 그래프)**: `University ➔ Department ➔ Track ➔ ExamType` 노드 네트워크를 Pyvis 물리 엔진으로 조작.
  * **뷰 2 (LLM 개체 추출 그래프)**:
    - LLM이 PDF 원문에서 문맥으로 새로 찾아낸 신규 개체(`llm_discovered=True`, 🆕 별표 노드) 표시.
    - PageRank 기반 노드 크기 + Louvain 알고리즘 기반 군집 색상화.
    - 동시출현 가중치 필터 슬라이더 (1~10).
    - "사전에 없던, LLM이 새로 찾아낸 개체 Top 10" 실시간 분석표 제공.
