## 이 파일 사용 규칙
- 새 작업 세션을 시작할 때 이 파일 맨 위 "다음에 할 일"부터 확인한다.
- 의미 있는 작업 단위(기능 완성, 버그 수정 묶음, 데이터 배치 등)가 끝나면 "로그"에 날짜별로
  한 항목씩 추가한다(무엇을/왜/결과 중심으로 3~5줄, 코드 스니펫이나 장황한 설명은 넣지 않음).
- "다음에 할 일"은 완료되면 지우고, 세션 중 새로 발견된 할 일(예: 이번의 "중앙대 실내환경디자인
  잔여 확인")은 바로 추가한다.
