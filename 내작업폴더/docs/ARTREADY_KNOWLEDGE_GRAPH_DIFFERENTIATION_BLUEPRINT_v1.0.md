## 1. ⚔️ 왜 지식그래프인가? (3대 입시 기술 패러다임 비교)

일반 수험생과 미술학원이 겪는 가장 큰 고통은 **"블로그, 학원 광고, 일반 AI의 거짓말(환각)"**입니다.

| 비교 차원 | ① 기존 입시 사이트 (진학사, 유웨이) | ② 일반 LLM / Vector RAG 챗봇 | ③ 🎨 ART:READY 지식그래프 엔진 (우리 서비스) |
| :--- | :--- | :--- | :--- |
| **핵심 데이터 구조** | RDBMS 정량 테이블 (수능/내신 백분위) | 텍스트 청크 벡터 임베딩 (유사도 검색) | **고차원 속성 지식그래프 (Property Graph)** |
| **실기/도구 이해도** | **전무** (인문/자연계 위주) | 단어 유사도만 매칭 (맥락 오해) | **도구 68종 허용/금지 관계 100% 엣지 결속** |
| **환각 (Hallucination)** | 없음 (단, 데이터 자체가 없음) | **매우 심각** (연도/시간/절수 지어냄) | **원천 0%** (모든 팩트가 노드 속성에 고정) |
| **다단계 전형 추적** | 단순 텍스트 표기 | 1단계 컷과 2단계 실기 배수 혼동 | `(Track)-[:STAGED]->(Step1)->(Step2)` 구조화 |
| **실기일 중복 판정** | 학생이 달력 보고 직접 대조 | 날짜 계산 오류 빈번 | `[:HAS_SCHEDULE]` 노드 간 일자 충돌 자동 차단 |
| **출신고교(일반고 vs 예고)** | 지원자격 적합 여부만 표시 | 구체적 유불리 분석 불가 | 고교 미술 이수단위 대비 실기비율 서브그래프 투영 |
| **근거 증명 (Audit)** | 요강 PDF 링크 텍스트 | 없음 또는 잘못된 출처 인용 | **노드 ID 및 공식 요강 페이지 1:1 결속 영수증** |

## 2. 🧩 실측 온톨로지 스키마 구조 (Data-Level Ground Truth)

백엔드에 구축된 지식그래프는 다음 8대 핵심 노드와 관계망으로 완벽히 얽혀 있습니다.

```mermaid
graph TD
    Univ["🏛️ Admission_University<br/>(가천대, 경희대 등 16개교)"]
    Dept["🎨 Admission_Department<br/>(회화과, 시각디자인과 등 31개)"]
    Track["📋 Admission_Track<br/>(실기우수자, 학생부종합 등)"]
    Exam["🖌️ Admission_ExamType<br/>(기초디자인, 소묘, 수채화)"]
    Sched["📅 Admission_Schedule<br/>(원서접수, 실기일, 발표일)"]
    Topic["📝 Admission_PastTopic<br/>(최근 기출주제 원문)"]
    Mat["🧰 Allowed_Material<br/>(수채화물감, 연필, 포스터칼라)"]
    Est["🔒 Admission_CutoffEstimate<br/>(추정컷 - Zero-Mixing 격리)"]

    Univ -->|HAS_DEPARTMENT| Dept
    Dept -->|HAS_TRACK| Track
    Track -->|REQUIRES_EXAM| Exam
    Track -->|HAS_SCHEDULE| Sched
    Exam -->|HAD_PAST_TOPIC| Topic
    Exam -->|ALLOWS_MATERIAL| Mat
    Track -.->|ESTIMATED_CUTOFF (격리)| Est
```

### 지식그래프가 보장하는 결정적 정밀도 (Deterministic Rules)
1. **Zero-Mixing 원칙**: 공식 요강 팩트(`official_facts`)와 학원가 추정치(`estimates`)는 절대 같은 노드에 섞이지 않고, 관계 타입부터 분리(`REQUIRES_EXAM` vs `ESTIMATED_CUTOFF`)하여 **공식 데이터 오염 원천 차단**.
2. **연도 불일치 조작 방지 (v1.0 Guard)**: `source_url` 내 연도 표기와 `admission_year`가 1년이라도 다르면 적재 단계에서 자동 거부 (2026/2027 데이터 세탁 원천 차단).

## 3. 🚨 현재 Vercel 사이트(`artready-gamma`)의 결핍과 사용자 페인포인트

사용자님의 **"아직 부족한데.. 차별화에 맞춰서 다시 한번 더 조사해!"**라는 지적은 정곡을 찌른 통찰입니다:

- **문제점 1: 지식그래프의 압도적 존재감이 UI에서 보이지 않음**
  - 백엔드에는 31개 학과의 거대한 지식그래프망이 구축되어 있는데, 정작 프론트엔드에서는 단순 텍스트 카드 몇 장으로만 보여지고 있습니다.
  - 사용자는 "이게 지식그래프인지, 그냥 엑셀 필터링인지" 체감할 수 없습니다.
- **문제점 2: 다중 홉(Multi-Hop) 추론의 부재**
  - "내가 가진 도구(연필+물감) ➔ 갈 수 있는 대학들 ➔ 그중 실기일이 안 겹치는 6개 조합"이라는 **그래프 최단 경로 탐색**이 한 번에 시각적으로 제시되지 않습니다.
- **문제점 3: 출신고교 가중치 필터 미적용**
  - `profile.html`에 "고교유형은 아직 매칭에 반영 안 됨"이라는 문구가 노출되어 있어 전문성에 아쉬움을 줍니다.

## 4. 🚀 지식그래프 기반 4대 초격차 킬러 기능 설계 (Killer Differentiation)

### 1) [Live Knowledge Graph 캔버스 뷰어 (인터랙티브 시각화)]
- **적용 위치**: `results.html` 및 `qa.html` 상단
- **기능**:
  - 수험생이 "기초디자인"을 선택하면 화면 중앙에 **[기초디자인 노드]**가 뜨고, 거미줄처럼 **14개 대학 노드가 연결되며, 각 대학의 실기 날짜와 허용 도구 뱃지가 실시간 물리 시뮬레이션(Force-Directed Graph)**으로 유려하게 펼쳐집니다.
  - 특정 대학을 클릭하면 해당 대학의 세부 요강 노드와 기출문제 노드가 줌인(Zoom-in)되어 학부모에게 **"AI가 100% 완벽한 데이터 지도로 관리한다"**는 압도적 시각적 신뢰를 선사합니다.

### 2) [그래프 기반 '수시 6장 무충돌 독립집합' 자동 설계기]
- **원리**: 실기고사 일정이 겹치는 대학 간에는 `[:CONFLICTS_WITH]` 관계가 형성됩니다.
- **알고리즘**: 지식그래프 상에서 **"충돌 엣지가 0개인 최대 독립 집합(Maximal Independent Set)"**을 계산하여, 수험생의 도구에 맞는 최적의 6개 대학 포트폴리오를 1초 만에 조합해 줍니다.

### 3) [지식그래프 100% 팩트 영수증 (Verification Receipt)]
- 모든 매칭 결과와 QA 답변에 **"지식그래프 원천 영수증"** 드로어 버튼 제공:
  - `검증 경로`: `Admission_Track(경희대 실기우수자) ➔ REQUIRES_EXAM(인체수채화) ➔ ALLOWS(붓, 연필, 켄트지 2절)`
  - `원천 출처`: 경희대 2027 수시요강 p.72 PDF 즉시 보기 링크
  - `무환각 보증`: 그래프 노드 불변 해시(Hash) 대조 통과 마크 출력

### 4) [고교 유형 서브그래프 투영 (일반고 vs 예고 분기 엔진)]
- **일반고 선택 시**: 실기 70%~90% 노드에 가중치를 부여하여, 내신 감점을 실기력으로 뒤집을 수 있는 대학군을 상단에 자동 랭킹.
- **예술고 선택 시**: 미술활동보고서 및 포트폴리오 노드에 가중치를 부여하여, 교과 이수단위의 강점을 극대화하는 서류형 대학군 매칭.
