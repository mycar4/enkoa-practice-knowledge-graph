## 1. 개요
LLM 정보추출 파이프라인에서 도출된 지식그래프 인스턴스(트리플)의 신뢰도를 보장하기 위해, 5대 정량 품질 지표의 수학적 정의와 오류 탐지/교정 규칙을 표준화합니다.

---

## 2. 5대 핵심 품질 지표 정의

### 1) 스키마 준수율 (Schema Compliance Rate)
- **정의**: 전체 추출 트리플 중 사전 정의된 온톨로지 규칙(허용 엔터티 타입, 허용 관계 타입)을 완벽히 지킨 비율.
$$\text{Schema Compliance} = \frac{\text{스키마 통과 건수}}{\text{전체 추출 건수}} \times 100\%$$

### 2) 근거 원문 일치율 (Evidence Grounding Match Rate)
- **정의**: 추출된 트리플의 증거 인용구(`quote`)가 실제 원천 텍스트(공시 XML 본문, 요강 원문)에 정확히 존재하는 비율.
$$\text{Grounding Match Rate} = \frac{\text{원문에 quote가 실존하는 건수}}{\text{전체 추출 건수}} \times 100\%$$

### 3) 샘플 정밀도 (Sample Precision)
- **정의**: 스키마와 원문 일치 2대 필터를 모두 통과한 후보군 중 무작위 표본(Sample)을 추출하여 도메인 전문가/규칙 기반으로 실제 참(True)으로 판정된 비율.
$$\text{Sample Precision} = \frac{\text{표본 중 정답 판정 건수}}{\text{표본 크기 } N} \times 100\%$$

### 4) 골드 표준 대조 성능 지표 (Gold Standard Evaluation)
정답 트리플 집합($G$)과 추출 트리플 집합($E$)의 1:1 대조:
- **TP (True Positive)**: 정답 집합에 있고 추출에도 성공한 트리플 ($E \cap G$)
- **FP (False Positive)**: 추출했으나 정답 집합에는 없는 허위/환각 트리플 ($E - G$)
- **FN (False Negative)**: 정답 집합에 있으나 추출하지 못한 누락 트리플 ($G - E$)

$$\text{Precision (정밀도)} = \frac{TP}{TP + FP}, \quad \text{Recall (재현율)} = \frac{TP}{TP + FN}$$
$$\text{F1 Score} = 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}$$

### 5) 오류 교정 개선도 (Correction Gain)
$$\Delta \text{F1} = \text{F1}_{\text{after}} - \text{F1}_{\text{before}}$$

## 3. 검증 스키마 및 가드 규칙

### 1) [DART-Trace] 스키마 가드
```python
ALLOWED_DART_ENTITIES = {"Company", "Shareholder", "EvidenceFragment"}
ALLOWED_DART_RELATIONS = {
    ("Shareholder", "HOLDS_ECONOMIC_STAKE", "Company"),
    ("Company", "BACKED_BY_EVIDENCE", "EvidenceFragment")
}
# 제약조건: stake_ratio는 0.0 초과 100.0 이하의 실수
```

### 2) [ART:READY] 스키마 가드
```python
ALLOWED_ART_ENTITIES = {"University", "AdmissionTrack", "PracticalType", "ExamSchedule"}
ALLOWED_ART_RELATIONS = {
    ("University", "OFFERS_TRACK", "AdmissionTrack"),
    ("AdmissionTrack", "REQUIRES_PRACTICAL", "PracticalType"),
    ("AdmissionTrack", "EXAM_ON", "ExamSchedule")
}
# 제약조건: practical_ratio는 0.0 이상 100.0 이하의 실수
```

## 4. 3대 오류 분류 체계 및 교정 전략

| 오류 유형 | 오류 현상 (Failure Mode) | 실사례 예시 | 표준 교정 전략 (Remedy) |
| :--- | :--- | :--- | :--- |
| **1. 타입 오류** (Type Error) | 존재하지 않는 엔터티/관계 임의 생성 | `(:Investor)-[:INVESTED_IN]->(:Corp)` | 표준 온톨로지 매핑 테이블 치환 |
| **2. 인용 환각** (Quote Hallucination) | 원문에 없는 단어를 요약하여 인용구로 제시 | 원문은 "80%", quote는 "실기비중 80퍼센트" | 퍼지 스트링 매칭 또는 원문 정밀 인덱싱 |
| **3. 모순 충돌** (Conflict Error) | 동일 주주에 대해 기준일자가 다른 복수 지분율 | 국민연금 7.25% vs 7.35% 동시 존재 | 최신 공시 접수번호(`rcept_no`) 우선 채택 |
