## 🧬 3. Pydantic 구조화 출력 스키마 명세

```python
from typing import List, Literal, Optional
from pydantic import BaseModel, Field

# 온톨로지 정의와 100% 일치하도록 Literal Enum 제약
ArtRelationName = Literal[
    "OFFERS_TRACK", "BELONGS_TO", "REQUIRES_PRACTICAL", "EXAM_ON"
]
ArtNodeType = Literal[
    "University",
    "Department",
    "AdmissionTrack",
    "PracticalType",
    "ExamSchedule",
]


class ArtTriple(BaseModel):
  """단일 트리플 추출 스키마"""

  subject: str = Field(description="주어 개체명 (원문에 등장한 그대로)")
  subject_type: ArtNodeType = Field(description="주어 노드 타입")
  relation: ArtRelationName = Field(description="온톨로지 허용 관계")
  object: str = Field(description="목적어 개체명 (원문에 등장한 그대로)")
  object_type: ArtNodeType = Field(description="목적어 노드 타입")
  evidence: str = Field(
      description="이 사실을 직접 뒷받침하는 요강 원문 문장/표"
  )


class ArtCoTExtraction(BaseModel):
  """CoT 다단계 추론 컨테이너"""

  reasoning: str = Field(description="1단계 개체 식별 -> 2단계 관계 판정 추론")
  triples: List[ArtTriple] = Field(description="유효한 트리플 목록")
```

## 🧪 4. 3단계 무결성 정제 필터 알고리즘

### [1단계] 근거 대조 (Ground Check)
```python
def ground_check(
    evidence: str, raw_text: str, subject: str, object_: str
) -> bool:
  if not evidence or evidence not in raw_text:
    return False
  ev_lower = evidence.lower()
  return (subject.lower() in ev_lower) and (object_.lower() in ev_lower)
```

### [2단계] 시그니처 검사 (Signature Check)
```python
def check_signature(row: dict, signatures: dict) -> bool:
  rel = row.get("relation")
  if rel not in signatures:
    return False
  subj_type, obj_type, _ = signatures[rel]
  return (row.get("subject_type") == subj_type) and (
      row.get("object_type") == obj_type
  )
```

### [3단계] 복합키 중복 제거 (Drop Duplicates)
```python
def drop_duplicates(rows: list[dict]) -> list[dict]:
  seen = set()
  unique_rows = []
  for row in rows:
    key = (row["subject"].lower(), row["relation"], row["object"].lower())
    if key not in seen:
      seen.add(key)
      unique_rows.append(row)
  return unique_rows
```

## 🌐 5. Neo4j Cypher 멱등 적재 패턴 및 계층 명세

### 1) 노드 패턴 생성 (Node Pattern)
```cypher
// 표준 복합키 식별자 노드 생성
MERGE (t:AdmissionTrack {track_id: $track_id})
ON CREATE SET t.name = $track_name, t.year = $year

// 미등록 개체 격리 노드
MERGE (c:Candidate {name: $candidate_name})
ON CREATE SET c.isolated_at = datetime()
```

### 2) 관계 생성 및 근거 등급 불변식 (Evidence Invariant)
```cypher
MERGE (t)-[r:REQUIRES_PRACTICAL]->(p:PracticalType {name: $practical_name})
ON CREATE SET 
    r.evidence = $evidence,
    r.evidence_level = $evidence_level,
    r.created_at = datetime()
ON MATCH SET
    r.evidence_level = CASE 
        WHEN r.evidence_level = 'curated' THEN 'curated' 
        ELSE $evidence_level 
    END
```
