# 지식그래프 구축·적재: 환경 구축 가이드

파이썬 라이브러리와 Neo4j Desktop 은 지난 그래프DB 단원에서 이미 갖췄다는 전제입니다.
여기에는 **이 단원에서 더 필요한 것만** 담았습니다. 위에서부터 순서대로 따라가세요.
**APOC → `import` 폴더 → `apoc.conf` → `.env` → 점검** 입니다.

> **Neo4j 는 반드시 "실습 전용" 데이터베이스에 연결하세요.** 모든 노트북이 서두에서 그래프를 **모두 지우고**
> 새로 만듭니다. 학생용 기본값은 자기 로컬(`bolt://localhost:7687`, 지난 그래프DB 단원에서 설치)이며,
> 접속 정보는 `.env` 로만 바꿉니다(노트북에 포트·비밀번호를 적지 마세요).

## 1. APOC 플러그인 설치

`apoc.load.json`·`apoc.version`·`apoc.meta.stats` 를 씁니다.

- [ ] Neo4j Desktop 인스턴스의 **Plugins** 에서 **APOC** 를 설치합니다.
- [ ] 설치 후 **인스턴스를 껐다 켭니다.** 재시작해야 플러그인이 올라옵니다.
- [ ] 확인: Query 편집기에서 `RETURN apoc.version();` 이 버전 문자열을 돌려주면 된 것입니다.

## 2. `import` 폴더 경로 확인

`LOAD CSV` 와 `apoc.load.json` 은 **서버가** 파일을 읽습니다. 그래서 데이터 파일이 그 인스턴스의
`import` 폴더 안에 있어야 하고, 노트북은 파일을 `file:///파일명.csv` 로 부릅니다.

**찾는 방법은 두 가지입니다. 둘 다 운영체제를 가리지 않습니다.**

**(1) Desktop 화면에서**: 인스턴스 카드의 관리 메뉴 **[...]** → **Open** → **Instance folder** 를 누르면
탐색기(Finder)가 그 인스턴스의 폴더를 엽니다. 그 안의 **`import`** 가 목적지입니다.

**(2) Query 편집기에서** (경로를 글자로 확인하고 싶을 때):

```cypher
SHOW SETTINGS YIELD name, value
WHERE name IN ['server.directories.neo4j_home', 'server.directories.import']
RETURN name, value;
```

- [ ] 찾은 경로를 `.env` 의 `NEO4J_IMPORT_DIR`(4번) 에 적으면 각 노트북의 **복사 셀**이 `data/` 의 파일을
      그 폴더로 자동 복사합니다. 경로를 못 찾겠으면 비워 두고, (1) 로 연 `import` 폴더에 `data/` 의
      CSV·JSON 을 직접 복사해도 됩니다.
- [ ] 교안_03 1절에서 만드는 **UTF-8 변환본**(`seoul_metro_stations_utf8.csv`)도 함께 복사해야 합니다.
      노트북이 그 자리에서 복사 셀을 한 번 더 실행하도록 되어 있습니다.

## 3. `apoc.conf` 만들기 (`apoc.load.json` 파일 읽기 허용)

APOC 는 설치만 해서는 **파일을 읽지 못합니다.** 따로 켜 줘야 합니다(`LOAD CSV` 를 여는 설정과는 별개입니다).

- [ ] 2번에서 연 폴더에서 `import` 와 나란히 있는 **`conf`** 폴더로 들어갑니다.
- [ ] 그 안에 **`apoc.conf`** 파일을 **새로 만듭니다.** 설치할 때는 생기지 않는 파일이라 직접 만들어야 합니다.
- [ ] 내용은 두 줄입니다.

```properties
apoc.import.file.enabled=true
apoc.import.file.use_neo4j_config=true
```

- [ ] **인스턴스를 껐다 켭니다.**

> **Windows 메모장으로 만들 때**: 저장 창의 *파일 형식*을 **모든 파일(\*.\*)** 로 바꾸고 이름을 `apoc.conf` 로
> 적으세요. 그냥 저장하면 `apoc.conf.txt` 가 되어 적용되지 않습니다.
>
> **macOS 에서**: 터미널 한 줄이 편합니다.
> ```bash
> printf 'apoc.import.file.enabled=true\napoc.import.file.use_neo4j_config=true\n' \
>   >> "위에서_찾은_경로/conf/apoc.conf"
> ```
>
> Neo4j 5 부터 이 설정을 **`neo4j.conf` 에 적으면 무시됩니다.** 반드시 `apoc.conf` 에 적으세요.

## 4. 접속 정보(`.env`) 채우기

- [ ] 이 폴더의 `.env.example` 을 복사해 **`.env`** 로 만듭니다.
- [ ] `NEO4J_URI` / `NEO4J_USER` / `NEO4J_PASSWORD` 를 **자기 실습 전용 DB** 값으로 채웁니다.

```dotenv
NEO4J_URI=bolt://localhost:7687
NEO4J_USER=neo4j
NEO4J_PASSWORD=내가-정한-비밀번호
NEO4J_IMPORT_DIR=2번에서-찾은-경로
```

> **노트북에는 주소·비밀번호를 적지 않습니다.** 접속 정보는 `.env` 로만 설정합니다.

## 5. 연결·환경 점검

- [ ] 각 노트북 맨 위의 **준비 셀(`# [제공 코드]`)** 을 위에서부터 실행합니다. `Neo4j 연결: ...` 이 찍히는지 봅니다.
- [ ] 교안_03 에는 **환경 점검 셀**이 있습니다. APOC 설치 여부, `LOAD CSV` 의 `import` 폴더 접근,
      `apoc.load.json` 의 파일 적재 권한 셋을 먼저 확인해 줍니다. 여기서 걸리면 아래 표로 해결한 뒤 진행하세요.

| 증상 | 십중팔구 원인 | 할 일 |
|---|---|---|
| `ServiceUnavailable` / 연결 거부 | 인스턴스가 멈춰 있거나 주소·포트가 다름 | 인스턴스를 켜고 `.env` 의 `NEO4J_URI` 확인 |
| `AuthError` / 인증 실패 | `.env` 의 사용자·비밀번호가 실제와 다름. **`.env` 를 아직 안 만든 경우도 여기로 떨어집니다** | 4번 |
| `ModuleNotFoundError: neo4j` | 커널이 이 프로젝트의 `.venv` 가 아니거나 라이브러리가 없다 | 커널을 **Python 3 (ipykernel)** 로 바꾸고 `uv add jupyter neo4j python-dotenv pandas` |
| `Node Key constraint requires Neo4j Enterprise Edition` | **커뮤니티 에디션**에 붙었다. Docker·Homebrew 의 기본 `neo4j` 이미지가 그렇다 | **Neo4j Desktop** 인스턴스로 바꿔 붙는다(Desktop 에는 Enterprise 개발자 라이선스가 딸려 온다) |
| `$(...)` 문법에서 `Invalid input` | Neo4j 가 **5.26 미만**이다 | 5.26 이상 버전으로 인스턴스를 만든다 |
| `Unknown function 'apoc.version'` · `There is no procedure with the name apoc.load.json` | APOC 미설치이거나 설치 후 재시작을 안 했다 | 1번 |
| `Import from files not enabled` | `apoc.conf` 가 없거나 이름이 `apoc.conf.txt` 다 | 3번 |
| `Couldn't load the external resource at: file:/...` | `import` 폴더에 파일이 없다 | 2번(복사 셀 또는 직접 복사) |
| 한글이 깨져 보인다 | 원본이 `CP949` 다 | 교안_03 1절의 UTF-8 변환을 먼저 돌린다 |
