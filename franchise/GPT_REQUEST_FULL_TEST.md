# GPT에게 그대로 전달할 요청문

`franchise/ANTIGRAVITY_FULL_TEST_SCENARIOS_v1.0.md`에 있는 아래 **39개 항목을 하나도
빠짐없이, 번호 순서대로** 실제 프로덕션 URL에 curl로 직접 실행해줘. 카테고리로
뭉쳐서 요약하지 말고, **번호마다 개별로** curl 명령 + 실제 응답 + 문서의 "기대 결과"와
대조한 PASS/FAIL을 표로 남겨줘. 지난번 요청 때 아래 목록 중 상당수가 통째로
누락됐었어서, 이번엔 체크리스트로 하나씩 확인하면서 진행해줘.

**주의**: 2.6과 2.10은 문서(v1.0)가 보안 수정 이전에 작성돼서 "로그인 없이도
200이면 정상"이라고 돼 있는데, 이건 낡은 기준이야. 실제로는 로그인 없으면
`401`이 나오는 게 맞는 동작이니 `401`이 나오면 PASS로 판정해줘(문서 원문 기대값이
아니라 이 지침을 따를 것).
