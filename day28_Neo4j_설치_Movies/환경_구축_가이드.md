# Neo4j 환경 구축 가이드

실습을 시작하기 전에 갖춰야 할 것만 담았습니다. 위에서부터 순서대로 따라가세요.
**라이브러리 설치 → Neo4j 설치 → 접속 정보(`.env`) → Movies 예제 적재 → 연결 확인** 입니다.

> 이 단원은 **읽기 전용**입니다. Movies 예제 그래프를 **조회만** 하고 초기화하거나 새로 만들지 않습니다.

## 1. 파이썬 라이브러리 설치

- [ ] 터미널에서 실행합니다.

```bash
uv add jupyter neo4j python-dotenv pandas
```

| 패키지 | 쓰는 곳 |
|---|---|
| `neo4j` | 파이썬에서 데이터베이스에 붙는 공식 드라이버(준비 셀의 `GraphDatabase`) |
| `python-dotenv` | 접속 정보를 적어 둔 `.env` 를 읽어 온다 |
| `pandas` | 조회 결과를 표로 다룬다(과제 LV2) |
| `jupyter` | 노트북 실행 환경. VS Code 커널용 `ipykernel` 이 함께 깔린다 |

- [ ] VS Code 로 노트북을 열고 커널을 **Python 3 (ipykernel)**(= 방금 만든 `.venv`)로 고릅니다.

## 2. Neo4j 설치

둘 중 하나만 하면 됩니다. **처음이면 A(Desktop)** 를 권장합니다. 화면별 자세한 설명은 교안_01 의 1절에 있습니다.

### A. Neo4j Desktop (로컬 설치, 권장)

- [ ] <https://neo4j.com/deployment-center/> 의 **Neo4j Desktop** 목록에서 **가장 최신 버전**을 고르고, 자기 운영체제 파일을 내려받습니다.
  - **Windows**: `Windows (x86 exe)` 를 받아 실행하고 안내대로 설치합니다.
  - **macOS**: `Mac (Universal dmg)` 를 받습니다. Apple Silicon(M 시리즈)과 Intel 이 **같은 파일 하나**라 칩을 따질 필요가 없습니다. 받은 `.dmg` 를 열고 Neo4j Desktop 아이콘을 **Applications** 폴더로 끌어다 놓으면 설치됩니다.
  - **Linux**: `Linux (x86 AppImage)` 를 받아 실행 권한을 주고(`chmod +x`) 실행합니다.
- [ ] **Create instance** 를 눌러 만듭니다. 이름(예: `practice`) · 버전은 **기본값** · 사용자 `neo4j` · 비밀번호는 직접 정하고 **꼭 기억**합니다.
- [ ] **만들면 인스턴스가 곧바로 시작됩니다.** 카드가 **Stopped(멈춤)** 로 보일 때만 재생 버튼을 눌러 켜세요. 실습 중에는 인스턴스 하나만 켜 둡니다(같은 포트를 쓰기 때문에 다른 것을 켜면 이쪽이 멈춥니다).
- [ ] 접속 정보는 인스턴스 카드에서 확인합니다. 로컬 기본값은 `bolt://localhost:7687` · 사용자 `neo4j` · 비밀번호는 방금 정한 값입니다.

> 비밀번호를 잊었다면 인스턴스를 **멈춘 뒤** 카드의 관리 메뉴(**[...]**)에서 재설정합니다. 다시 만들 필요 없습니다.

### B. Neo4j Aura (클라우드, 설치 없이)

- [ ] <https://neo4j.com/product/auradb/> 에서 **AuraDB Free** 인스턴스를 만듭니다.
- [ ] 만들면 접속 정보가 화면에 한 번 뜹니다. **파일로 내려받는 버튼**이 함께 있으니 그걸 누르세요. `.txt` 한 장이 받아지고, 그 안에 아래 값이 들어 있습니다.

```text
NEO4J_URI=neo4j+s://xxxxxxxx.databases.neo4j.io
NEO4J_USERNAME=neo4j
NEO4J_PASSWORD=(한 번만 보여 주는 값)
```

- [ ] 이 파일을 잃어버리지 마세요. **URI 와 사용자 이름은** 나중에 콘솔의 인스턴스 카드에서 다시 볼 수 있지만, **비밀번호는 다시 못 봅니다.** 잊었다면 콘솔에서 재설정해야 합니다.
- [ ] 며칠 쓰지 않으면 인스턴스가 **자동으로 일시중지**됩니다. 다음 실습 때 콘솔에서 **Resume** 를 눌러 다시 켜세요.

## 3. 접속 정보(`.env`) 채우기

- [ ] 이 폴더의 `.env.example` 을 복사해 **`.env`** 로 만듭니다.
- [ ] `NEO4J_URI` / `NEO4J_USER` / `NEO4J_PASSWORD` 를 **자기 실습 전용 DB** 값으로 채웁니다(로컬 기본은 `bolt://localhost:7687`).
- [ ] (Aura 를 만들었다면) `AURA_URI` / `AURA_USER` / `AURA_PASSWORD` 도 채웁니다. 교안_01 3-2절의 **원격 연결 실습**에서만 씁니다. 안 만들었으면 비워 두세요.

채우고 나면 `.env` 는 이런 모양입니다(`.env.example` 과 이름·순서가 같습니다).

```dotenv
# 로컬 Neo4j Desktop (교안_02 와 과제는 전부 이 값을 씁니다)
NEO4J_URI=bolt://localhost:7687
NEO4J_USER=neo4j
NEO4J_PASSWORD=내가-정한-비밀번호

# Neo4j Aura (교안_01 의 원격 연결 실습에서만. 안 만들었으면 값 없이 비워 둡니다)
AURA_URI=neo4j+s://xxxxxxxx.databases.neo4j.io
AURA_USER=neo4j
AURA_PASSWORD=내려받은-파일의-비밀번호
```

> ⚠️ **내려받은 Aura 파일을 그대로 붙여넣지 마세요.** 그 파일의 키 이름이 `NEO4J_URI`·`NEO4J_PASSWORD` 라서 위쪽 **로컬 설정을 덮어씁니다.** 값만 옮기고 이름은 `AURA_*` 로 바꿔 적으세요.

| Aura 파일의 줄 | `.env` 에 적을 이름 |
|---|---|
| `NEO4J_URI=neo4j+s://...` | `AURA_URI=neo4j+s://...` |
| `NEO4J_USERNAME=neo4j` | `AURA_USER=neo4j` |
| `NEO4J_PASSWORD=...` | `AURA_PASSWORD=...` |

> 로컬은 `bolt://`, Aura 는 `neo4j+s://` 로 시작합니다. `+s` 는 인터넷을 건너가는 **암호화 연결**이라는 뜻입니다.

> **노트북에는 주소·비밀번호를 적지 않습니다.** 접속 정보는 `.env` 로만 설정합니다.

## 4. Movies 예제 그래프 적재

- [ ] 이 폴더의 **`data/movies_setup.cypher`** 를 열어 **전체 내용을 복사**합니다.
- [ ] **Query** 편집기(Desktop 사이드바 **Tools → Query**, 또는 인스턴스 카드의 **Connect** 드롭다운)에 붙여넣고 실행합니다.
- [ ] 노드 **171**개·관계 **253**개가 만들어졌다는 요약이 뜨면 적재 완료입니다.

> 이 스크립트는 `MERGE` 로 적혀 있어 **두 번 실행해도 같은 노드가 겹쳐 생기지 않습니다.** 중간에 실패했다면 그냥 다시 실행하세요.

## 5. 연결 확인

- [ ] 노트북 맨 위 **준비 셀**을 실행해 `Neo4j 연결: ...` 이 찍히는지 봅니다.
- [ ] 이어서 **점검 셀**을 실행해 `연결된 그래프의 노드 수: 171` 이 나오면 환경 구축이 끝났습니다(`0` 이면 4번을 아직 안 한 것입니다).

| 증상 | 십중팔구 원인 | 할 일 |
|---|---|---|
| `ServiceUnavailable` / 연결 거부 | 인스턴스가 멈춰 있거나(Aura 는 일시중지) 주소·포트가 다름 | 인스턴스를 켜고(Aura 는 Resume) `.env` 의 `NEO4J_URI` 확인 |
| `AuthError` / 인증 실패 | `.env` 의 사용자·비밀번호가 실제와 다름. **`.env` 를 아직 안 만든 경우도 여기로 떨어집니다** | 3번을 수행하거나 비밀번호를 고친다 |
| 노드 수가 **0** | Movies 를 아직 적재하지 않음 | 4번을 수행한 뒤 점검 셀 다시 실행 |
| `ModuleNotFoundError: neo4j` | 커널이 이 프로젝트의 `.venv` 가 아님 | 커널을 **Python 3 (ipykernel)** 로 바꾸고 1번 확인 |
