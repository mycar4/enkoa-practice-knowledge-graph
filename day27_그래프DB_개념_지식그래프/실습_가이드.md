## 1. 교안_01: 관계형 데이터베이스 vs 그래프 (순수 파이썬 + pandas + networkx)

- [ ] **1. 왜 그래프인가**: 온라인 쇼핑 3개 표를 두 번 `merge` 하는 번거로움 vs 인접 dict 로 이웃 곧장 따라가기(개념도 2장). 따라하기(영화 그래프 인접 dict)·퀴즈.
- [ ] **2. LPG 모델**: 노드·레이블·관계(방향)·속성을 dict/list 로 모델링(해부도 1장). **관계에 붙는 속성**까지 시연. 따라하기(영화 그래프 레이블별 세기)·퀴즈.
- [ ] **3. 차수**: 나가는 차수·들어오는 차수로 그래프를 한 줄 요약. 따라하기(영화별 시청자 수)·퀴즈(관계 필터·막다른 노드).
- [ ] **4. 그래프 순회**: 1홉·2홉(역방향 인접 dict, 2홉 추천, 순회 그림 1장). 따라하기(재현에게 영화 추천)·퀴즈.
- [ ] **5. networkx 시각화**: `DiGraph`·`add_node`·`add_edge`·`draw`(한글 폰트, 결과 그림 1장). 따라하기(영화 시청 그래프 그리기)·퀴즈.
- [ ] **🚀 응용 클론코딩**: 두 고객의 공통 구매 상품 찾기(`common_products`).

## 2. 교안_02: 온톨로지·지식그래프·RDF·SPARQL (Wikidata 실질의)

> 이 교안은 **데이터 파일을 쓰지 않습니다.** 공개 지식 그래프 Wikidata 에 SPARQL 로 직접 질의해
> 사실을 받아 옵니다.

- [ ] **준비**: Wikidata 를 누가 만들고 관리하는지, 잘못된 편집을 어떻게 막는지 읽기 → `run_sparql` 제공 셀 실행 → **연결 확인 셀**에서 `알베르트 아인슈타인` 이 찍히는지 본다.
      엔드포인트는 두 곳(수업 주력 QLever, 위키미디어 공식 query.wikidata.org)을 씁니다.
- [ ] 데이터 살펴보기 실행(`PEOPLE_QIDS`·`fetch_facts`·`triples` 준비: 인물 11명의 국적·직업 사실 100개 안팎).
- [ ] **1. 지식 그래프란**: 사실 = 연결. 트리플을 문장으로 읽기, 인물별 사실 수 세기. 따라하기(모나리자의 사실)·퀴즈.
- [ ] **2. 온톨로지**: 원본의 직업 값이 56종 안팎으로 잘게 나뉜 것을 확인 → 담을 규격 정의 + 검증 함수(`is_valid`) → **규격 통과분만 남겨 `kg_triples`**(38/100 안팎). 퀴즈로 확인(이 절은 개념 설명과 시연 중심이라 따라하기가 없습니다).
- [ ] **3. RDF 트리플 vs LPG**: 주어-술어-목적어, URI(주소)로 가리키기, LPG 비교표(`triple_to_lpg(트리플, 규칙)`), 리터럴(숫자·언어 태그). 퀴즈로 확인.
- [ ] **4. SPARQL(rdflib)**: `kg_triples` 를 rdflib `Graph` 로 옮기고 **Turtle·N-Triples** 로 확인 → `SELECT ?person WHERE { ... }` 직접 실행 → 패턴 두 줄을 **같은 변수로 잇기(조인)**.
- [ ] **4-1. 타입·규칙 적기**: `rdf:`(사실상 `rdf:type` 하나)와 `rdfs:`(`label`·`subClassOf`·`domain`·`range`)의 차이를 읽고, `a` 로 타입을, `rdfs:subClassOf` 로 상위 개념을, `rdfs:domain`·`rdfs:range` 로 술어의 주어·목적어 타입을 적는다. Turtle 로 결과 확인.
- [ ] **4-2. 조건 걸기·다듬기**: `UNION` → `DISTINCT` → `OPTIONAL`(없으면 빈칸) → `FILTER NOT EXISTS` → `ASK` → `BIND`+`CONTAINS`/`REGEX`.
- [ ] **4-3. 속성 경로**: `술어1/술어2` 로 두 걸음을 한 줄에. 두 줄 조인이 한 줄로 줄어드는 것을 확인.
- [ ] **4-4. 질의로 그래프 만들고 고치기**: `CONSTRUCT`(결과가 표가 아니라 새 그래프) · `INSERT DATA`·`DELETE DATA` 와 조건 기반 `DELETE`·`INSERT ... WHERE`(`graph.update`).
- [ ] 따라하기 2개(작품→작가→국적 조인, `UNION` 으로 두 국적 고르기)·퀴즈 4문.
- [ ] **5. 공개 엔드포인트**: `wd:`·`wdt:`·`VALUES`·`SERVICE wikibase:label` 읽기 → 공식 엔드포인트로 실질의(429 로 거절당하면 그 뜻을 읽고 표준 SPARQL 판으로 이어 간다) → `COUNT` 로 원본 규모 확인.
- [ ] **5-1. 계층 타고 올라가기**: `wdt:P279`(상위 개념) 목록 확인 → `wdt:P106/wdt:P279*` 로 하위 직업까지 포함했을 때 인원이 얼마나 늘어나는지 대조.
- [ ] 따라하기(조건 바꿔 원본에 질의)·퀴즈.
- [ ] **🚀 응용 클론코딩**: SPARQL `GROUP BY`·`COUNT` 로 직업별 인원 세기.
- [ ] **다음 시간 준비**: Neo4j Desktop 내려받기(설치·실행은 다음 시간에 함께 합니다).
