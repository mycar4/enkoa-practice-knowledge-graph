# 🛡️ [안티그라비티 개발준수 철칙] 다른 프로젝트 적용 가이드

본 폴더는 Antigravity AI 에이전트의 **중복 실행 방지, 코드 개발 전면 금지(순수 QC 전담), 실측 기반 보고, 표준 지시 및 3단 결과 보고 프로토콜(SOP)**을 다른 프로젝트나 워크스페이스에 즉시 이식하기 위해 구축된 독립 표준 자산 패키지입니다.

---

| 파일명 | 권장 배치 위치 (타 프로젝트 기준) | 역할 및 효과 |

## 🚀 다른 프로젝트(폴더)에 10초 만에 적용하는 방법

새로운 프로젝트(예: `C:\MyNewProject`)를 시작하실 때, 다음 중 편하신 방법 1가지를 선택하시면 됩니다:

### [방법 1] 가장 간단한 방법 (프로젝트 루트에 복사)
1. 본 `안티그라비티_개발준수_철칙` 폴더 내의 **`AGENTS.md`**와 **`GEMINI.md`** 파일을 새 프로젝트 루트(`C:\MyNewProject\`)에 복사해 넣습니다.
2. 새 프로젝트에서 Antigravity를 열면 AI가 자동으로 **"실 개발 금지, 순수 QC 전담, 실측 보고, 3단 고정 양식 회신"** 모드로 즉시 동작합니다.

### [방법 2] 컴퓨터 전체(모든 프로젝트)에 영구 자동 적용하는 방법
이미 현재 PC의 전역 설정 경로에 본 규칙이 등록되어 있습니다:
* **전역 적용 위치**: `C:\Users\Playdata\.gemini\config\rules\self_verification_guard.md`
* 따라서 사용자님의 PC에서는 어떤 폴더에서 Antigravity를 실행하더라도 제1조~제7조 규칙이 기본 탑재되어 작동합니다.

## 💡 AI에게 일 시키실 때의 마법의 한 줄 (SOP)
> **`"[대상]에 대해 [합격 기준]을 기준으로 [검수해 / 모니터링해 / 실측 보고해]."`**
> 
> * 예시: *"새로 작성된 app.py 파일에 대해 문법 에러 0건을 기준으로 검수해."*
> * 에이전트는 사족 없이 **[1단: Raw Data] ➔ [2단: 실측 대조표] ➔ [3단: 최종 판정]**으로만 회신합니다.
