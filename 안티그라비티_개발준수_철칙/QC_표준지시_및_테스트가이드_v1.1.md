## 📋 [신설] QC 에이전트 표준 지시 및 결과값 수신 가이드 (SOP)

사용자님께서 AI 에이전트에게 검수나 모니터링을 시키실 때, **불필요한 감정 소모나 사족 없이 100% 팩트 결과만 뽑아내는 표준 프로토콜**입니다.

### 1. 사용자 지시 표준 템플릿 (3대 필수 요소)
사용자님은 다음 3가지만 지정하여 단문으로 지시하시면 됩니다:
```text
[지시 형식]
"[대상(Target)]에 대해 [합격 기준(Threshold)]을 기준으로 [지시어(검수/모니터링/실측보고)]해."
```

---

### 2. AI 에이전트 3단 결과 보고 고정 양식 (사족 전면 금지)
에이전트는 변명이나 "열심히 했습니다" 식의 문장 없이, 오직 아래 3단 구조로만 보고합니다:
```markdown
### 1단: 실행 명령 및 원시 데이터 (Raw Data)
- 실제 실행한 명령어 / Cypher 쿼리 원문
- 시스템이 반환한 JSON 또는 로그 텍스트 원본

### 2단: 물리적 실측 대조표 (Ground-Truth Comparison Table)
| 검증 항목 | 합격 기준 (Threshold) | 물리적 실측치 (Actual) | 판정 (PASS/FAIL) |

### 3단: 최종 판정 (Verdict)
- ALL PASS ✅ (또는 FAIL ❌: 에러 파일/라인 번호/에러 코드만 출력)
```

---

### 3. 실전 지시 및 결과값 수신 샘플 3종

#### [샘플 1: 프로덕션 DB 상태 점검]
* **사용자 지시**:
  > *"프로덕션 DB 현황에 대해 노드 89,000개 이상, OWNS_STAKE=0건을 기준으로 실측 보고해."*
* **에이전트 회신 예시**:
  ```markdown
  ### 1단: 실행 명령 및 원시 데이터 (Raw Data)
  > MATCH (n) WITH count(n) AS nodes MATCH ()-[r:OWNS_STAKE]->() RETURN nodes, count(r) AS owns_stake;
  {"nodes": 89139, "owns_stake": 0}

  ### 2단: 물리적 실측 대조표
  | 검증 항목 | 합격 기준 (Threshold) | 물리적 실측치 (Actual) | 판정 |
  | :--- | :--- | :--- | :---: |
  | 전체 노드 수 | >= 89,000개 | 89,139개 | PASS ✅ |
  | OWNS_STAKE 관계 | == 0건 (불변식) | 0건 | PASS ✅ |

  ### 3단: 최종 판정
  👉 ALL PASS ✅ (프로덕션 DB 무결성 정상)
  ```

#### [샘플 2: 소스 코드 변경 사전 검수]
* **사용자 지시**:
  > *"이번에 변경된 `decision_report_service.py` 파일의 diff를 확인하고, 4단 리포트 반환 키(tier1~4) 누락 여부를 검수해."*
* **에이전트 회신 예시**:
  ```markdown
  ### 1단: 실행 명령 및 원시 데이터 (Raw Data)
  > git diff 내작업폴더/services/decision_report_service.py
  (실제 diff 출력 원본)

  ### 2단: 물리적 실측 대조표
  | 검증 항목 | 합격 기준 | 물리적 실측치 | 판정 |
  | :--- | :--- | :--- | :---: |
  | tier1_facts 키 존재 | True | True | PASS ✅ |
  | tier2_interpretations 키 존재 | True | True | PASS ✅ |
  | tier3_evidence 키 존재 | True | True | PASS ✅ |
  | tier4_next_actions 키 존재 | True | True | PASS ✅ |

  ### 3단: 최종 판정
  👉 ALL PASS ✅ (4단 구조 완전성 검증 완료)
  ```

#### [샘플 3: 서버 프로세스 헬스체크]
* **사용자 지시**:
  > *"Streamlit 서버 상태에 대해 포트 8501 응답 여부를 모니터링해."*
* **에이전트 회신 예시**:
  ```markdown
  ### 1단: 실행 명령 및 원시 데이터 (Raw Data)
  > python -c "import socket; s=socket.socket(); print(s.connect_ex(('127.0.0.1', 8501)))"
  ExitCode: 0 (Connected)

  ### 2단: 물리적 실측 대조표
  | 검증 항목 | 합격 기준 | 물리적 실측치 | 판정 |
  | :--- | :--- | :--- | :---: |
  | Port 8501 Socket | 0 (열림) | 0 (열림) | PASS ✅ |

  ### 3단: 최종 판정
  👉 ALL PASS ✅ (Streamlit 대시보드 정상 서비스 중)
  ```
