## 시작하기

### 1. 환경 만들기 — uv

이 저장소는 [uv](https://docs.astral.sh/uv/) 로 파이썬 환경을 관리합니다. `pyproject.toml`·`uv.lock` 이
들어 있으므로 **명령 한 줄이면 수업과 똑같은 환경**이 만들어집니다.

```bash
# uv 가 없다면 먼저 설치 (macOS·Linux)
curl -LsSf https://astral.sh/uv/install.sh | sh

# 저장소를 받은 폴더에서
uv sync            # .venv 생성 + 잠긴 버전 그대로 설치
```

VS Code 로 노트북을 열고 커널은 **Python 3 (ipykernel)** (= 방금 만든 `.venv`)를 고릅니다.

### 2. 인터넷 연결 — day27

day27 의 **교안_02** 는 파일 대신 **공개 지식 그래프 Wikidata** 에 직접 질의해 데이터를 받아 옵니다.
API 키는 필요 없지만 **인터넷 연결이 필요합니다**. 사내망·방화벽이 막혀 있으면 첫 셀부터 에러가 납니다.

과제(LV1·LV2)는 **로컬 파일과 rdflib** 만 쓰므로 인터넷 없이 풀립니다. 단 LV2 마지막 문제만
원본에 직접 질의하는데, 연결이 안 되면 **그 문제만** 채점을 건너뜁니다.

> 공개 엔드포인트는 요청이 몰리면 `429`(요청 제한)로 거절합니다. 교안이 그 뜻과 대처를 함께 다룹니다.

### 3. Neo4j — day28 부터

다음 일차부터 그래프 전용 데이터베이스 **Neo4j** 를 씁니다. day27 의 마지막 절에 내려받는 방법이
